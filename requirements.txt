# Upper bounds matter here. mcp 2.0 removed mcp.server.fastmcp (it became
# mcp.server.mcpserver) and starlette 1.0 is likewise a breaking release, so an
# unpinned rebuild resolves to versions this server does not import against.
# Render never hit this because its build predates those releases; a fresh
# Cloud Run build did, immediately.
mcp[cli]>=1.0.0,<2.0.0
starlette>=0.40.0,<1.0.0
uvicorn>=0.30.0,<1.0.0
PyGithub>=2.0.0,<3.0.0
